# Bili UP Monitor · B站 UP 主监控系统

面向多账号日常运营的本地 B站数据监控工具。集中查看博主投稿与互动表现，按分组对比数据、跟进月度目标，并通过 JSON 文件在不同电脑之间迁移数据。

## 上游项目与二次开发说明

**本项目基于 [miaoihan/YourBili](https://github.com/miaoihan/YourBili) 的源码进行二次开发，不是从零编写的独立原创项目。** 原作者为 [miaoihan](https://github.com/miaoihan)，原项目提供了基础页面、B站数据采集、SQLite 数据存储、趋势快照和监控调度等能力。

## 主要功能

| 功能 | 用法 |
| --- | --- |
| 月度看板 | 查看指定月份、最近 1／3／6 个自然月或自定义日期范围的投稿、播放和互动数据 |
| 四级分组 | 自定义四级目录，账号可放入任一级；筛选父级时包含所有下级账号 |
| 博主监控库 | 按名称、UID、备注、分组、状态和最后投稿时间等查看账号 |
| 最近六条视频 | 每个博主展开显示最近六条已入库视频，不受统计月份限制 |
| 月度目标 | 手动设置账号或分组的投稿、播放、点赞、评论、投币、收藏等目标，后续月份沿用数值并重新统计进度 |
| 博主／分组对比 | 自选两个或多个博主，或同一级的分组；查看排名和 A／B 差值 |
| Excel 统计 | 导出真实 .xlsx，范围与当前对比选择绑定，包含分组路径、投稿、播放和互动等数据 |
| 备注 / 待办 | 点击「备注」或双击监控库里的博主行编辑；本地显示名和备注不会被采集覆盖 |
| 月报通知 | 每月 1 日首次进入时提醒上一完整自然月的数据，历史通知可在通知中心查看 |
| 跨电脑迁移 | 下载 JSON，再到另一台电脑上传；迁移账号、分组、备注、目标、视频、快照、任务与月报状态 |
| 定时监控 | 在本地服务运行期间按计划采集，记录成功、失败及数据完整状态 |

## 普通用户：下载便携版

进入 [Releases 下载页面](https://github.com/z2x7d54/bili-up-monitor/releases)，下载 Windows x64 ZIP。

1. 完整解压到可写目录，打开其中的 YourBili 文件夹。
2. 双击「启动服务.bat」。网页、后端接口和定时监控会一起启动。
3. 浏览器通常会自动打开 http://127.0.0.1:3000/。端口被占用时，以启动窗口显示的地址为准。
4. 在「博主监控库」添加 B站 UID 或空间链接，再按需要设置分组、月度目标和备注。
5. 停止时双击「停止服务.bat」。

便携版面向 Windows 10／11 64 位电脑，自带 Node.js、依赖及编译文件，无需安装 Git、Node.js、npm 或数据库服务器。请完整解压后运行，保留启动窗口；关闭浏览器不会停止监控，关闭电脑后则无法采集。

便携版不包含原电脑的账号、视频、通知、目标、Cookie 或备份，仅保留默认分组和默认任务。

## 跨电脑同步备注和数据

在 A 电脑进入「设置 → 跨电脑数据互通」，点击「下载数据」。将 JSON 文件带到 B 电脑，在同一位置上传。

- 支持最大 100 MB 的 JSON 数据文件。
- 按 UID 合并账号，按月份合并月报，重复上传不会重复创建同一账号。
- 新电脑会从文件恢复本地显示名、备注和待办。
- 默认保留本机已有的显示名和备注，空白处从文件补入。
- 要用 A 电脑修改后的备注更新 B 电脑已有账号，请勾选「用文件中的显示名和备注更新本机同账号」；勾选后以文件内容为准，包括已清空的备注。
- 旧文件没有备注字段时，仍保留本机备注。上传前自动保存本机数据备份。
- Cookie 与本机设置不随 JSON 迁移。Excel 用于统计对比，不能作为完整迁移文件上传。

## 数据口径

- 日期按中国标准时间（Asia/Shanghai）计算。
- 投稿数按所选期间的视频发布时间统计；播放与互动是这些视频截至最近一次采集的累计值，不是期间新增流量。
- 最近 N 个月包含本月，共 N 个自然月；本月只统计到当前时间。
- 1h／24h／7d 增长需要足够的历史快照。缺少可比较数据时显示空缺，不当作真实增长。
- 采集失败或数据尚未补齐时标注「待补齐」，不直接判断为零投稿或断更。
- 分组筛选包含下级账号；不同层级分组可能包含同一账号，跨层级汇总不能直接相加。

## 开发者：从源码运行

源码仓库不包含便携运行环境、安装后的依赖、编译产物和个人数据库。需要 Node.js 24，以及与 v6 锁文件兼容的 pnpm 8。

~~~powershell
git clone https://github.com/z2x7d54/bili-up-monitor.git
cd bili-up-monitor
npm install -g pnpm@8
pnpm install --frozen-lockfile
Copy-Item .env.example .env
pnpm db:generate
pnpm db:push
pnpm build
node scripts/launcher.cjs
~~~

停止源码启动的服务：

~~~powershell
node scripts/launcher.cjs --stop
~~~

开发模式可使用 pnpm dev。修改源码后，需要重新构建才能更新正式启动的网页。

需要自行制作 Windows 便携包时，先准备 runtime/node.exe（Windows x64 Node.js 24），完成依赖安装和构建并停止服务，再运行「打包分享.bat」。该脚本会生成空白数据库并排除本机数据、日志、环境文件与备份。

## 技术与目录

Next.js 16、React 19、TypeScript、Tailwind CSS、Prisma 6、SQLite。

~~~text
src/app/          页面与 API
src/components/   看板、对比、目标、通知、备注等界面
src/lib/          B站采集、统计、导入导出与本地任务调度
prisma/           数据模型
scripts/          初始化、启动、停止与便携打包
patches/          依赖修补
third-party/      第三方许可证
~~~

数据库位于 data/yourbili.db，仅在本机创建。服务默认绑定本机地址。可选 B站 Cookie 在设置页填写并保存在本机数据库中，请不要提交 .env、data、日志、备份或 Cookie 到仓库。
